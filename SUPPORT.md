# Support

Use GitHub issues for reproducible bugs, import problems, feature requests,
documentation improvements and setup questions. Choose the matching issue form
so the report contains the details needed to investigate it.

This is a community-maintained project. Response times vary, and support is
best effort. Include the version you are running, your deployment method and a
small set of reliable reproduction steps.

Do not post real survey exports, database files, credentials, network
identifiers or precise locations. Security vulnerabilities must be reported
privately as described in [SECURITY.md](SECURITY.md).
